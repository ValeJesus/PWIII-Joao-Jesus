# 💻 Criando um Projeto Java com VS Code

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado e configurado:

- Extensão **Extension Pack for Java** (Microsoft)
- Extensão **Spring Boot Extension Pack**, que disponibiliza o Spring Boot Dashboard e o assistente do Spring Initializr
- JDK instalado e configurado



## 🚀 Passo a passo

1. Abra o **VS Code**.
2. Pressione `Ctrl + Shift + P` para abrir a **Paleta de Comandos**.
3. Digite e selecione **Spring Initializr: Generate a Maven Project** ou a opção equivalente para Gradle.
4. Escolha a **linguagem**:
   - Java
   - Kotlin
   - Groovy
5. Escolha a versão do **Spring Boot**.
6. Informe o **Group Id** (ex: `com.example`).
7. Informe o **Artifact Id** (ex: `demo`).
8. Escolha a versão do **Java**.
9. Escolha o **Packaging**:
   - Jar
   - War
10. Selecione as **dependencies** desejadas, como:
    - Spring Web
    - Lombok
    - Spring Boot DevTools
11. Confirme a seleção pressionando **Enter**.
12. Escolha a pasta onde o projeto será salvo.
13. O VS Code irá gerar automaticamente a estrutura do projeto.
14. Por fim, escolha se deseja abrir o projeto na janela atual ou em uma nova janela.
