# 🟦 TypeScript

O **TypeScript** é um **superset do JavaScript** que adiciona **tipagem estática** à linguagem.

Ele permite definir os tipos de dados utilizados no código, ajudando a identificar possíveis erros durante o desenvolvimento.

## 🚀 Vantagens

- Detecta erros antes da execução do código
- Oferece melhor autocomplete e suporte da IDE
- Torna o código mais seguro e previsível
- Facilita a manutenção e organização de projetos maiores
- Melhora a experiência durante o desenvolvimento

## 📄 Extensões de Arquivo

Os arquivos utilizados para escrever código TypeScript possuem as seguintes extensões:

- `.ts` → arquivos TypeScript
- `.tsx` → arquivos TypeScript que utilizam JSX, como componentes React
