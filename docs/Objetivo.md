# 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de:

- Aprender e praticar **React**
- Desenvolver componentes reutilizáveis e aplicar **componentização**
- Utilizar **TypeScript** no desenvolvimento da aplicação
- Trabalhar com ferramentas modernas, como o **Vite**
- Aprimorar a organização e estruturação de projetos frontend
