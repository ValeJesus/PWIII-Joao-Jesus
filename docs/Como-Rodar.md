# ⚙️ Como Executar o Projeto

## 1️⃣ Pré-requisitos

Antes de começar, certifique-se de que você possui as seguintes ferramentas instaladas:

- Node.js
- npm (geralmente instalado junto com o Node.js)

Verifique as versões instaladas com:

```bash
node -v
npm -v

2️⃣ Clonar o Repositório
Clone o repositório utilizando o Git:

git clone <url-do-repositorio>
cd tic-taka-toe

3️⃣ Instalar as Dependências
Instale todas as dependências do projeto com:

npm install

Esse comando instala automaticamente todas as bibliotecas e pacotes definidos no arquivo package.json.

4️⃣ Executar o Projeto
Inicie o projeto em modo de desenvolvimento com:

npm run dev

Após a inicialização, o projeto estará disponível localmente.

🚀 Scripts Disponíveis
Comando	Descrição
npm run dev	Inicia o projeto em modo de desenvolvimento
npm run build	Gera a versão otimizada para produção
npm run preview	Executa localmente a versão de produção
