# ⚛️ React

O **React** é uma biblioteca JavaScript utilizada para a **construção de interfaces de usuário**.

Ele permite desenvolver aplicações utilizando **componentes reutilizáveis**, facilitando a organização, manutenção e evolução do código.

## 🧩 Principais conceitos utilizados no projeto

- **Componentes** → partes reutilizáveis da interface
- **Props** → dados enviados de um componente para outro
- **State (estado)** → dados que podem ser alterados durante a execução da aplicação
- **Renderização dinâmica** → atualização automática da interface conforme os dados são modificados
