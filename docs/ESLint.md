# ESLint

O **ESLint** é uma ferramenta utilizada para **analisar, verificar e padronizar o código**.

## 🛠️ Principais benefícios

- Evita erros comuns no código
- Mantém um padrão de desenvolvimento
- Melhora a legibilidade
- Ajuda a identificar problemas antes da execução
- Facilita a manutenção do projeto
